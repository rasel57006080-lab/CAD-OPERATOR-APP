# CAD Operator Vercel App

A professional CAD Operator portfolio + tools starter built with Next.js.

## Run locally
1. Install Node.js 18+.
2. Open this folder in terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open `http://localhost:3000`

## Deploy to Vercel
1. Create a GitHub repository and upload this project.
2. Go to Vercel and import the GitHub repository.
3. Framework: Next.js (auto-detected).
4. Click Deploy.

## Customize
Edit `app/page.js` for name, projects, contact details and portfolio items.
Edit `app/globals.css` for colors and layout.
